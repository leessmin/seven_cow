# seven_cow
本项目是七牛云2025秋季校招实项目实战题目（议题二）

## 题目详情
议题二
开发一个利用 AI 来做角色扮演的网页，用户可以搜索自己感兴趣的角色例如哈利波特、苏格拉底等并可与其进行语音聊天。

请回答：
你计划将这个网页面向什么类型的用户？这些类型的用户他们面临什么样的痛点，你设想的用户故事是什么样呢？
你认为这个网页需要哪些功能？这些功能各自的优先级是什么？你计划本次开发哪些功能？
你计划采纳哪家公司的哪个 LLM 模型能力？你对比了哪些，你为什么选择用该 LLM 模型？
你期望 AI 角色除了语音聊天外还应该有哪些技能？

请开发以上网页，包括实现 3 个以上 AI 角色应该具备的技能。要求不能调用第三方的 Agent 能力，只需允许调用 LLM 模型、语音识别以及 TTS 能力。针对以上 1-4 点，请把你的思考整理成文档，作为作品的说明一并提交。

本项目开发环境：
- 开发系统：Arch Linux
- 需要Unix依赖：[python-openai-whisper](https://archlinux.org/packages/extra/any/python-openai-whisper/)。 如果否则无法进行语音识别
- 数据库：PostgreSQL
- 后端语言：Go
- 前端框架：react(react-router)

## 问题回答
1. 你计划将这个网页面向什么类型的用户？这些类型的用户他们面临什么样的痛点，你设想的用户故事是什么样呢？

答：我设计的网页主要是面向需要感情安慰、又或者是二次元用户，我让ai模仿某一个人、或者某个动漫角色的说话方式，已达到可以让用户和自己心爱之人（动漫角色）聊天

2. 你认为这个网页需要哪些功能？这些功能各自的优先级是什么？你计划本次开发哪些功能？

答：如果是一个商业项目，则需要登陆注册等一系列基础的权限校验，以及创建自己喜欢的ai角色与自己聊天。功能优先级：创建ai角色聊天。本次计划开发如下：

- 登陆注册（时间有限，所以目前采用匿名的方式登陆注册，用户无需手动注册）
- 创建ai角色
- 与ai进行对话

3. 你计划采纳哪家公司的哪个 LLM 模型能力？你对比了哪些，你为什么选择用该 LLM 模型？

答：采用openAI的chatgpt，目前用的比较多，其他模型说出来的语言没有chatgpt有感情，所以在当前业务下，我选择了chatgpt

4. 你期望 AI 角色除了语音聊天外还应该有哪些技能？

答案：除了语音聊天，我认为ai应该具备比如帮用户完成一些自动化的操作，或者自启动。如用户可以让ai到达某个时间点时提示用户。又或者可以在饭点等提醒用户吃饭之类的
